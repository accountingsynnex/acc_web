อัตราส่วนทางการเงิน

คำนวณสดจากงบดุลและงบกำไรขาดทุนที่โรลอัปจากไฟล์ที่นำเข้า — ทั้ง 3 แท็บ (Thailand/Taiwan/SET) แสดงอัตราส่วนชุดเดียวกัน กลุ่มเดียวกัน ลำดับเดียวกันทุกตัว เทียบกันได้ตรงบัตรต่อบัตร ต่างกันแค่สูตรที่ใช้คำนวณในแต่ละแท็บ (ดูรายละเอียดในช่อง "สูตร" ท้ายการ์ด)

อัตราส่วนทางการเงิน — SYNNEX Thailand

สูตรของบริษัทเอง (Conso/MD&A) — ใช้ยอดปลายงวดล้วน ไม่มีค่าเฉลี่ย ไม่ต้อง annualize (ยกเว้นวงจรเงินสด ดูด้านล่าง — ลูกหนี้การค้ารวมส่วนที่ไม่หมุนเวียน และสินค้าคงเหลือหักค่าเผื่อสินค้าเสื่อมสภาพแล้ว ตามงบที่เผยแพร่)

แนวโน้มรายไตรมาส

ใช้งวดที่บันทึกไว้ที่หน้า Import → งวดที่บันทึกไว้ เรียงเก่า→ใหม่ ต่อท้ายด้วยงวดปัจจุบัน — สูตรเดียวกับการ์ดด้านบนทุกตัว (วงจรเงินสดยังเป็นยอดปลายงวดล้วน ไม่เฉลี่ย)

เป้าหมาย (KRI) — เส้นประในกราฟ: วัน

อัตราส่วนทางการเงิน — SYNNEX Taiwan

วงจรเงินสด, Quick Ratio และ ROE เป็นสูตรจริงจากไฟล์ Synnex Thai PAR (แท็บ NROIC/KPI) — เฉลี่ยต้นเดือน+ปลายเดือนของทั้ง 3 เดือนในไตรมาส (จึงต้องมีงวดก่อนไตรมาส 1 เดือนด้วย) และอ่านลูกหนี้/สินค้าคงเหลือก่อนหักค่าเผื่อฯ กับเจ้าหนี้รวมเจ้าหนี้หมุนเวียนอื่น แต่หักสำรอง vendor และเงินจ่ายล่วงหน้าค่าสินค้า ตามที่ไฟล์ PAR ทำ และมี AR Vendor Days เพิ่มเข้ามาในวงจรเงินสด (ลูกหนี้เคลม vendor — metric เฉพาะไต้หวัน ไม่มีแถวนี้ใน Thailand/SET) ส่วนที่เหลือยังไม่พบสูตรไต้หวันแยก จึงใช้แบบเดียวกับ Thailand (ระบุไว้ในช่อง "สูตร" ของแต่ละการ์ด)

แนวโน้มรายไตรมาส

ใช้งวดที่บันทึกไว้ที่หน้า Import → งวดที่บันทึกไว้ เรียงเก่า→ใหม่ ต่อท้ายด้วยงวดปัจจุบัน — วงจรเงินสดที่นี่เฉลี่ยกับงวดก่อนหน้าในตารางนี้ (เทียบกันแบบ chain) ไม่ใช่คอลัมน์ยอดยกมาในไฟล์ที่นำเข้าแบบการ์ดด้านบน จุดแรกสุดจึงไม่มีค่าเฉลี่ยให้ใช้ (ใช้ยอดปลายงวดแทน)

เป้าหมาย (KRI) — เส้นประในกราฟ: วัน

อัตราส่วนทางการเงิน — SET

วงจรเงินสด และ ROA/ROE/Total Asset Turnover เป็นสูตรจริงจากผังเทียบ "Synnex KPI / SET / Taiwan" ของบริษัทเอง — AR Days รวม "ลูกหนี้หมุนเวียนอื่น" เข้ากับลูกหนี้การค้าด้วย และ AP Days รวม "เจ้าหนี้หมุนเวียนอื่น + ค่าใช้จ่ายค้างจ่าย" เข้ากับเจ้าหนี้การค้า (ตามบรรทัดในงบที่ส่ง SET), ROA/ROE/Asset Turnover ใช้สินทรัพย์/ส่วนของผู้ถือหุ้นเฉลี่ย + ปรับเป็นรายปีตาม toggle ด้านล่าง ส่วนที่เหลือเหมือนวิธีของ Thailand (ไม่มีสูตร SET เฉพาะ)

แนวโน้มรายไตรมาส

ใช้งวดที่บันทึกไว้ที่หน้า Import → งวดที่บันทึกไว้ เรียงเก่า→ใหม่ ต่อท้ายด้วยงวดปัจจุบัน — ROA/ROE/Asset Turnover ใช้ตัวคูณ annualize ตามจำนวนเดือนของแต่ละงวดเอง (จากรหัสงวด)
