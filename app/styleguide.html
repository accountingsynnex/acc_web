Style guide

ทุก component ที่แอปนี้มี พร้อมโค้ดให้คัดลอก — ถ้าสิ่งที่คุณกำลังจะสร้างมีอยู่ในหน้านี้แล้ว ให้ใช้ตัวนั้น อย่าสร้างใหม่ หน้านี้โหลด styles.css ตัวจริง ไม่มี override ของตัวเอง ดังนั้นสิ่งที่เห็นคือสิ่งที่จะได้จริง ๆ และ test/design.test.js จะทำให้ CI แดงถ้ามีปุ่มตัวไหนในเว็บมีขนาดไม่ตรงกับที่นี่

ปุ่ม — มี 3 ระดับ และมีแค่ 3

ทุก action ในทุกหน้าต้องเป็นหนึ่งใน 3 ตัวนี้ ไม่มีตัวที่ 4 ถ้ารู้สึกว่าต้องมีตัวที่ 4 แปลว่าโจทย์ยังไม่ชัด ไม่ใช่ว่าขาด component

<button class="btn">ปุ่มหลัก</button>
<button class="btn ghost">ปุ่มรอง</button>
<button class="btn danger">ลบข้อมูล</button>

.btn — สิ่งที่หน้านี้มีไว้ทำ หน้าละหนึ่งอัน · .btn.ghost — action สนับสนุน มีหลายอันได้ · .btn.danger — ลบข้อมูลที่กู้คืนไม่ได้

อย่าทำ: ใส่ style="..." ทับปุ่ม ถ้าปุ่มหน้าตาไม่ถูกต้อง ให้แก้ที่ styles.css ไม่ใช่ที่จุดเรียกใช้ — btn ghost เคยไม่มี CSS อยู่จริง ทุกที่ที่ใช้เลยต้องเขียนหน้าตาซ้ำเอง จนสามหน้าดูไม่เหมือนกัน

ลิงก์ ≠ ปุ่ม

.linkish คือลิงก์ที่อยู่ในประโยค ขนาดตัวอักษรวิ่งตามข้อความรอบตัว ถ้ามันอยู่ใน toolbar มันคือปุ่ม ให้ใช้ .btn.ghost

พบ 12 รหัสใหม่ ที่ยังจัดกลุ่มไม่ได้ — จับคู่ให้ครั้งเดียว ระบบจะจำไว้ใช้เดือนถัดไป
<span class="linkish">จับคู่ให้ครั้งเดียว</span>

สัญญาณว่าใช้ผิด: ถ้าต้องเขียน style="text-decoration:none" แปลว่ามันควรเป็นปุ่ม ไม่ใช่ลิงก์

สถานะ — chip

สีเดียวไม่พอเสมอ chip จึงมีจุดสีคู่กับข้อความ คนตาบอดสีอ่านได้ และปรินต์ขาวดำก็ยังอ่านออก

Debit = Credit ยังไม่ได้จัดกลุ่ม ไม่สมดุล ตรง budget 
<span class="chip good"><span class="dot"></span>Debit = Credit</span>

ช่องกรอก — fld

.fld จัด label กับ input ให้เอง ไม่ต้องตั้งระยะห่างเอง · ถ้าต้องใช้ class เพื่อให้ JS หาเจอ ให้ขึ้นต้นด้วย js- เสมอ

<div class="fld"><label>รหัสงวด</label><input type="text" /></div>
<div class="seg"><button class="on">ทั้งหมด</button><button>รหัสใหม่</button></div>

<!-- class สำหรับให้ JS หา ต้องขึ้นต้น js- และห้ามเอาไปใส่ style -->
<input class="js-ml-amt" />

สี

ใช้ตัวแปรเสมอ ห้ามเขียนเลขสีตรง ๆ — ทุกตัวมีคู่ของโหมดมืดอยู่แล้ว กดปุ่มมุมขวาบนดูได้

--accent
--good
--warn
--bad
--var-over
--var-under
--ink
--muted
--faint

--var-over / --var-under คือหมึกสำหรับตัวเลขผลต่างในตาราง แยกจาก --bad / --good เพราะสองตัวนั้นทำมาเพื่อ chip กับตัวเลขใหญ่ พอเอามาใช้กับตัวหนังสือขนาดตาราง contrast ตกต่ำกว่ามาตรฐาน

โครงหน้า

ทุกหน้าหน้าตาเหมือนกันเพราะใช้โครงเดียวกัน คัดลอกจากหน้าที่มีอยู่แล้ว อย่าเริ่มจากศูนย์

<body data-page="statements">          <!-- shell.js ใช้ highlight เมนู -->
  <aside class="side" id="side"></aside>   <!-- shell.js เติมให้ -->
  <div class="main">
    <div class="topbar">
      <div class="crumb">Output · <b>Statements</b></div>
      <div class="spacer"></div>
      <span class="selectish">…period picker…</span>
      <button class="iconbtn" id="themeBtn">…</button>
      <button class="btn">action หลัก</button>
    </div>
    <div class="content">
      <div class="page-head"><h1>…</h1><p>…</p></div>
      <section><h2 class="sec">หัวข้อ</h2> … </section>
      <div class="panel"> … </div>
    </div>
  </div>

ลำดับ <script> คือลำดับ dependency — ไม่มี module system มาคำนวณให้ ดู CONTRIBUTING.md

ถ้าจะเพิ่ม component ใหม่

1. เขียนกฎใน styles.css (ห้าม inline)  ·  2. เพิ่มตัวอย่างในหน้านี้  ·  3. ถ้ามันต้องเหมือนกันทุกหน้า ให้เพิ่มเข้า COMPONENTS ใน test/design.test.js แล้วรัน node test/design.test.js --update
